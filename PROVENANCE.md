# Code provenance

Hive IPP Bridge is an independent implementation based on observed network
behavior and interoperability testing against a legitimately installed PaperCut
Hive browser extension.

The independently authored project code is developed and maintained by
[Edge Case Software](https://edgecasesoftware.dev).

The repository must not contain or redistribute PaperCut extension source,
minified bundles, icons, certificates, captured authentication credentials, HAR
files, or other proprietary assets. Protocol names, field names, and endpoint
paths may be documented only as needed for interoperability.

The separate working directory contains private research artifacts and must not
be copied into release archives or source packages.
